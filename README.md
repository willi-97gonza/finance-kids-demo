# 💰 Finance Kids

### Aprende hoy, decide mejor mañana.

**Finance Kids** es una plataforma web educativa diseñada para enseñar educación financiera a niños y adolescentes mediante una experiencia interactiva y gamificada, inspirada en modelos de aprendizaje como Duolingo.

Su objetivo es facilitar el aprendizaje de conceptos como ahorro, ingresos, gastos, presupuestos e inversión, promoviendo hábitos financieros responsables desde edades tempranas.

## ✨ Características principales

- 📚 Aprendizaje organizado por niveles y lecciones.
- 🎮 Actividades interactivas y gamificación.
- 💰 Enseñanza de conceptos financieros básicos.
- 🐕 Kibo, mascota que acompaña la experiencia educativa.
- 🎨 Interfaz amigable y diseño adaptable.

## 🎯 Objetivo

Contribuir a la formación de generaciones con conocimientos financieros, capaces de administrar sus recursos y tomar mejores decisiones económicas mediante herramientas digitales educativas.

## 🎓 Contexto académico

Proyecto desarrollado en el marco de formación en desarrollo de software, aplicando conocimientos de programación, bases de datos, diseño web, arquitectura de software y buenas prácticas como SOLID, DRY, KISS y YAGNI.
